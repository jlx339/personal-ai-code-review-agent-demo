# Real Sample Dataset

Three distinct real historical Python samples from two projects are pinned in `manifest.json`, including source SHA-256 hashes. Each review adds an unmodified upstream buggy file to an isolated evaluation PR. The labels under `expected/` were prepared before model execution, using the source and linked upstream fixes. These are real code samples, not the original bug-introducing diffs. They focus on correctness; they do not establish security detection or benign-change precision. A byte-identical candidate is retained as a repeat measurement and excluded from aggregate scoring.

MIT attribution is preserved in `upstream/`. The upstream files are reviewed as text and are not imported or executed. Do not merge evaluation PRs. Baseline and follow-up diagnostics are in `results/`; the quality target was not met. Owner judgments are still required before claiming human-labeled precision. A partial run or missed issue remains visible. Do not publish evaluation findings without owner selection.
